🪷 About this pond

This example is a static-content project — a frogs project whose only config is webserve.json, naming a start page, a port, and (optionally) a custom 404 page: 

{
  "startPage": "index.html",
  "port": 8090,
  "notFoundPage": "404.html"
}

Beyond the start page, frogs resolves every request straight to a matching file on disk — css/style.css, js/app.js, this page itself — with a small built-in MIME table, safe path resolution (a .. in the URL is rejected outright, and a symlink pointing outside the project is caught too), and basic HTTP caching via ETag/Last-Modified.

A frogs project is always either an API (openapi.yaml) or a static site (webserve.json) — never both at once.
